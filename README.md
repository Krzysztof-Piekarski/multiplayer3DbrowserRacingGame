# multiplayer3DbrowserRacingGame

Temat pracy:
## Przeglądarkowa gra wyścigowa 3D multiplayer z wykorzystaniem biblioteki Three.js

Temat po angielsku: **3D multiplayer browser racing game using Three.js**

### Cel pracy:
Celem pracy jest projekt i implementacja przeglądarkowej, trójwymiarowej gry wyścigowej multiplayer. Ze względu na brak preinstalowanych zasobów po stronie użytkownika, modele 3D, tekstury oraz logika gry zostaną zoptymalizowane pod kątem szybkiego uruchamiania aplikacji oraz płynnej rozgrywki. Gra umożliwi wielu graczom dołączenie do wspólnej sesji rozgrywki niezależnie od wykorzystywanej platformy sprzętowej (komputer stacjonarny, smartfon, tablet), bez konieczności instalacji dodatkowego oprogramowania.

### Zadania do wykonania:
1. Opracowanie mechaniki gry wyścigowej, w tym zoptymalizowanego modelu fizyki pojazdów (z wykorzystaniem dostępnego silnika fizycznego lub autorskiego rozwiązania), systemu kolizji oraz zasad rozgrywki prowadzących do jednoznacznego wyłonienia zwycięzców.
2. Implementacja aplikacji klienckiej i serwerowej umożliwiającej rozgrywkę wieloosobową w czasie rzeczywistym, w tym synchronizację stanu gry pomiędzy graczami oraz płynne renderowanie grafiki 3D po stronie klienta (z wykorzystaniem biblioteki Three.js).
3. Po uruchomieniu serwera gracze będą mogli dołączyć do gry w sieci lokalnej bez jakichkolwiek preinstalowanych komponentów. Wszystkie niezbędne assety dostarczy serwer. Gra będzie ukończonym produktem- rozgrywka kończyć się będzie wskazaniem zwycięzców.
4. Zaprojektowanie responsywnego interfejsu użytkownika dostosowanego do różnych rozdzielczości i rozmiarów ekranów oraz implementacja systemu sterowania umożliwiającego obsługę gry zarówno przy użyciu klawiatury i myszy, jak i interfejsów dotykowych.
